# Seguridad

Si encuentras un problema de seguridad o de privacidad (por ejemplo, algo que envíe datos sin avisar), **no lo publiques como incidencia abierta**. Repórtalo en privado con _Security → Report a vulnerability_ en la página del repositorio de GitHub, y lo revisamos.

Lo que cuenta como problema serio:

- Que la app envíe audio, texto dictado o ajustes a algún servidor.
- Que un instalador publicado no corresponda al código del repositorio.
- Que se pueda leer el historial de una persona desde otra app sin su permiso.

Cómo verificar la privacidad por ti mismo: [`PRIVACY.md`](PRIVACY.md) y `bun run check:privacy`.
